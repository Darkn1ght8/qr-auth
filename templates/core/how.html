{% t "ШАГ 01 / 06" %}

{% t "Компьютер открывает страницу входа" %}

{% t "Браузер открывает /login и запрашивает у сервера новую QR-сессию. Вместе с запросом отправляется fingerprint браузера." %}

{% t "ШАГ 02 / 06" %}

{% t "Сервер создаёт временный токен" %}

{% t "Токен secrets.token_urlsafe(32), nonce и подпись HMAC. В базу записывается только хэш SHA-256. Браузер открывает канал WebSocket; QR обновляется каждые 30 с." %}

/qr/scan/<token>/<hmac>/ · TTL 60 s

{% t "ШАГ 03 / 06" %}

{% t "Телефон сканирует QR" %}

{% t "Телефон, на котором уже выполнен вход, считывает код. Сервер проверяет подпись и срок и переводит статус в scanned." %}

pending → scanned

{% t "ШАГ 04 / 06" %}

{% t "Компьютер узнаёт об этом мгновенно" %}

{% t "Через WebSocket на компьютер приходит «Подтвердите на телефоне». Если WebSocket недоступен — long-polling." %}

ws → {"status": "scanned"}

{% t "ШАГ 05 / 06" %}

{% t "Пользователь подтверждает" %}

{% t "На телефоне видны браузер, ОС, IP и время запроса (защита от QRLjacking). Кнопки «Подтвердить» или «Отклонить»." %}

scanned → confirmed | rejected

{% t "ШАГ 06 / 06" %}

{% t "Одноразовый код → сессия" %}

{% t "Сервер выдаёт компьютеру одноразовый код на 30 секунд. Браузер обменивает его на Django-сессию, токен удаляется. Повторное использование невозможно." %}

Set-Cookie: sessionid; HttpOnly; Secure; SameSite=Lax

{% t "Статусы сессии" %}
